# Setup

There is nothing to configure. The plugin connects to `https://btcdcaengine.com/mcp` over HTTPS and
works immediately — no account, no key, no sign-in.

The full guide ships as a skill, so Claude can answer setup questions in the session it is asked in:
[skills/connecting/SKILL.md](skills/connecting/SKILL.md). It covers the daily allowances, how to
connect a paid account with an API key, and what the common refusals mean.
